# P2 foundation and integration requests

- **Done (connect-everything):** Allow `CheckAndHoldResult.material_ready_date` to represent an unknown date when a shortage has no supplier lead time. The required date field currently uses `9999-12-31` internally in this case. Planning recognizes it and returns no promised option until the data is available. The REST material status already supports a null date.
- Add operation-level completion information for interrupted production. The scheduler can retain completed work and move unstarted slots. It needs the completed quantity or remaining run time for an interrupted operation before it can safely propose replacement work.
- **Done (connect-everything):** Refresh server-updated attributes before taking the post-update snapshot in `app.api.master_data.update_row`. Flushing a quotation update expired `updated_at`, and reading it in the synchronous snapshot raised `MissingGreenlet`. P2 snapshots the public quotation fields inside its owned router.
