# P5 implementation plan

Both views are Anatomy Heroes. The first build uses SVG, the kit already in the desktop app, and two auto-discovered routes.

## Factory floor

The shift floor is a concrete machine hall. Its beacons and machine displays report the production state, and a cart follows the aisle to a bay when a material issue can be linked to that bay.

| Assembly | Parts planned |
| --- | --- |
| Hall | Concrete deck, expansion joints, pedestrian stripes, bay borders, aisle markings, storage rack posts, feet, shelf beams, shelves, stock cases, pallet decks and skids |
| Office | Plinth, mullions, sills, glass panes, desk legs, desktop, monitor stand, monitor bezel, keyboard |
| Shared machine fittings | Bed, leveling feet, chip tray, side cabinet, ventilation slots, hinges, pull handles, panel screws, cable tray, keypad, screen bezel, beacon bracket, lens segments and cap |
| CNC and sheet metal | Lathe headstock, chuck, workpiece, tool rest and chip guard; mill bridge, spindle head, table and vice; brake side frames, ram and die; laser bed, cutting slats, bridge rails and cutting head |
| Workbenches | Granite inspection surface, legs, cross brace, height gauge upright, slider, probe, CMM arm and sample; packing table, shelf, carton flaps, parcel and tape dispenser |
| Transport | Cart chassis, wheels, handle, pallet and stock cases |

Use seeded bay coordinates and the `FloorOut` and `MachineOverview` contracts. Status changes update beacons immediately and refresh job and summary data. Open machine details by pointer or keyboard.

## Agent map

The control room routes message parcels along a conveyor between agent workstations and the orchestrator desk. The database vault represents persistent storage shared by the stations.

| Assembly | Parts planned |
| --- | --- |
| Room | Raised deck, seams, feet, conveyor beds, guide rails, rollers, transfer plates, rail supports, cable ducts and sockets |
| Console and vault | Desk pedestal, cross brace, countertop, monitor stands, three display bezels, keyboards, vault casing, door, locking bar, handle and drive trays |
| Order and Material | Scanner lid, output slot, paper tray, document stack, feeder, shelf posts, shelf beams, bins and scale platform |
| Planning and Quality | Plotting table, Gantt board, board frame, plotter bar, inspection bench, gauge upright, probe and samples |
| Monitoring and Maintenance | Screen brackets, monitor bank, control keys, tool cabinet, drawer fronts, drawer pulls, pegboard and tools |
| Simulator and shared station fittings | Simulator console, terminals, rack panels, station feet, attachment plates, counter bezels and queue lamps |

Use the agent summary and message contracts. Connect each message to a physical link, schedule parcels without overlaps within a link, and use the same routes for chronological order replay.

## Build and verification

1. Build reusable geometry, frame, visibility-aware motion and drawers inside P5 paths.
2. Connect REST, live events and mock fixtures. Mount the shared generator only in mock mode.
3. Run the requested tests and inspect the browser in both themes, including keyboard navigation, narrow layout and reduced motion.
4. Record validation and endpoint questions in the P5 docs and run the ownership check.
